# Kinetic Typography Studio — UI v0.1 (Phase 2)

**Date:** 2026‑06‑14
**Phase:** 2 — UI (clickable wireflow). Built on Concept v0.1.
**Artifact:** [`prototype/index.html`](../prototype/index.html) — open in any browser (self‑contained, no build,
no dependencies, placeholder animations).

> Goal of this phase: design the **experience and flow** with stand‑in animations, *before* wiring real
> animation logic (Function) or any export/Resolve plumbing (Technique).

## The wireflow (4 screens)

```
 INPUT ───Generate──▶ GALLERY ───Edit──▶ REFINE ───Export──▶ EXPORT
   ▲                     │                  │                   │
   └─────Edit line───────┘   └──Back──┘     └──────Back─────────┘
```

1. **Input** — one big line field (pre‑filled), compact globals (Duration chips, Format 16:9/9:16/1:1,
   optional *Vibe*), one bold **Generate** CTA. "Works with any DaVinci Resolve — free or Studio. 100% free."
2. **Gallery (the magic moment)** — a 3×3 grid of the **same line** rendered in **9 live‑animating looks**
   (Neon, Chrome, Glitch, Particles, Brutalist, Typewriter, Retro, Bold Pop, Gradient). Per card: label,
   ♥ favorite, hover **Edit →**. Top bar: edit line / regenerate.
3. **Refine (light editor)** — big checker‑backed preview (transparency hint) + scrubber, and a compact knob
   panel: **Speed, Intensity, Color, Font, In/Out**, plus **Surprise me** + **Duplicate**. *No timeline /
   keyframes* — curated knobs only (per the Hybrid, content‑creator decision). Color + Speed actually drive
   the preview to prove the "knob → live change" feel.
4. **Export** — Format (OGraf package / ProRes 4444 / PNG seq / WebM, all alpha), Resolution, FPS, Duration,
   Alpha ON; **Download**. A disabled **"Send to Resolve timeline · Studio"** button foreshadows the sync tier
   (free = download + drag; Studio = one‑click later).

## Decisions baked into this draft (defaults, adjustable on the go)

- **9 variants** shown at once (3×3).
- **Single line** input in v1.
- **Favorites** = ♥ per card (tray/compare can come later).
- **Vibe** present but optional (Auto default).
- **Dark, modern, creative** visual identity; magenta→cyan accent gradient; system fonts (no web‑font loading
  in the mockup). FREE badge in the header.
- **Checkerboard preview** backgrounds to signal transparency/alpha everywhere output is shown.

## Intentionally fake (placeholder) — to be real in later phases

- The 9 looks are **CSS placeholders**, not the final OGraf/GSAP animations (Function phase).
- Generate/Regenerate just re‑renders the same catalog with the typed line (no real "generation").
- Knobs are mostly visual (Color + Speed are wired for feel); Export buttons don't produce files yet.
- No persistence / projects screen yet.

## Open UI questions (non‑blocking, decide as we iterate)

- Exact grid count & how strongly variants should differ; a **favorites/compare tray**.
- Whether *Vibe* should bias generated colors/looks now or later.
- Mobile layout polish (grid already collapses 3→2→1).
- Empty/loading states, onboarding copy.

## v0.2 — Premium redesign (the "teuer & edel" direction)

Feedback on v0.1: the flat app screens looked "cheap / like a website builder." Reworked into a premium,
animated direction, researched against award‑tier references (see sources below). The app wireflow moved to
**`prototype/app.html`**; **`prototype/index.html`** is now the premium **landing page**.

**Design system (drop‑in tokens):**
- **Palette — "dark but not black":** warm espresso base `#0E0D0B`, surfaces `#16140F`/`#1C1917`, 1px
  hairlines `rgba(255,255,255,.07)`, warm off‑white text `#F4EFE6`, muted `#A29A8E`, **one** restrained accent —
  champagne gold `#D4A574` / `#EBDAB0`. (No neon, no blue→purple gradient, no pure black — all flagged as
  "cheap/AI‑template" tells.)
- **Type:** **Clash Display** (display, tight negative tracking) + **Satoshi** (body) — Fontshare, free
  commercial, *variable* (on‑brand for kinetic type). Avoid Inter/Space Grotesk.
- **Atmosphere:** SVG `feTurbulence` film‑grain overlay, slow blurred **aurora orbs**, tasteful glass nav,
  fine hairlines, 60‑30‑10 balance.
- **Motion stack (all MIT / GSAP‑free):** **Lenis** smooth scroll + **GSAP ScrollTrigger** (parallax scrub,
  batched reveals), masked word‑reveals on headings, **magnetic** buttons, **custom cursor**, velocity‑free
  CSS **marquee**, **vanilla‑tilt** cards. Gated by `prefers-reduced-motion`; **transform/opacity‑only**.
- **Resilience:** content is visible without JS; libraries (CDN) only *enhance*. If GSAP/Lenis fail to load,
  the page still reads premium (static).
- **Dogfooding:** the hero is itself live kinetic typography — the sample line cycles through the 9 looks,
  demoing the product on the landing page.

**Still placeholder:** the 9 looks are CSS stand‑ins; "Launch app" routes to the wireflow; no real
generation/export yet (Function/Technique phases).

*Next: get feedback on the premium look, then carry the same design tokens into the app screens

Dossier #1).*
