# Kinetic Typography Studio — UI v0.1 (Phase 2)

**Date:** 2026‑06‑14
**Phase:** 2 — UI (clickable wireflow). Built on Concept v0.1.
**Artifact:** [`prototype/index.html`](../prototype/index.html) — open in any browser (self‑contained, no build,
no dependencies, placeholder animations).

> Goal of this phase: design the **experience and flow** with stand‑in animations, *before* wiring real
> animation logic (Function) or any export/Resolve plumbing (Technique).

## The wireflow (4 screens)

```
 INPUT ───Generate──▶ GALLERY ───Edit──▶ REFINE ───Export──▶ EXPORT
   ▲                     │                  │                   │
   └─────Edit line───────┘   └──Back──┘     └──────Back─────────┘
```

1. **Input** — one big line field (pre‑filled), compact globals (Duration chips, Format 16:9/9:16/1:1,
   optional *Vibe*), one bold **Generate** CTA. "Works with any DaVinci Resolve — free or Studio. 100% free."
2. **Gallery (the magic moment)** — a 3×3 grid of the **same line** rendered in **9 live‑animating looks**
   (Neon, Chrome, Glitch, Particles, Brutalist, Typewriter, Retro, Bold Pop, Gradient). Per card: label,
   ♥ favorite, hover **Edit →**. Top bar: edit line / regenerate.
3. **Refine (light editor)** — big checker‑backed preview (transparency hint) + scrubber, and a compact knob
   panel: **Speed, Intensity, Color, Font, In/Out**, plus **Surprise me** + **Duplicate**. *No timeline /
   keyframes* — curated knobs only (per the Hybrid, content‑creator decision). Color + Speed actually drive
   the preview to prove the "knob → live change" feel.
4. **Export** — Format (OGraf package / ProRes 4444 / PNG seq / WebM, all alpha), Resolution, FPS, Duration,
   Alpha ON; **Download**. A disabled **"Send to Resolve timeline · Studio"** button foreshadows the sync tier
   (free = download + drag; Studio = one‑click later).

## Decisions baked into this draft (defaults, adjustable on the go)

- **9 variants** shown at once (3×3).
- **Single line** input in v1.
- **Favorites** = ♥ per card (tray/compare can come later).
- **Vibe** present but optional (Auto default).
- **Dark, modern, creative** visual identity; magenta→cyan accent gradient; system fonts (no web‑font loading
  in the mockup). FREE badge in the header.
- **Checkerboard preview** backgrounds to signal transparency/alpha everywhere output is shown.

## Intentionally fake (placeholder) — to be real in later phases

- The 9 looks are **CSS placeholders**, not the final OGraf/GSAP animations (Function phase).
- Generate/Regenerate just re‑renders the same catalog with the typed line (no real "generation").
- Knobs are mostly visual (Color + Speed are wired for feel); Export buttons don't produce files yet.
- No persistence / projects screen yet.

## Open UI questions (non‑blocking, decide as we iterate)

- Exact grid count & how strongly variants should differ; a **favorites/compare tray**.
- Whether *Vibe* should bias generated colors/looks now or later.
- Mobile layout polish (grid already collapses 3→2→1).
- Empty/loading states, onboarding copy.

## v0.2 — Premium redesign (the "teuer & edel" direction)

Feedback on v0.1: the flat app screens looked "cheap / like a website builder." Reworked into a premium,
animated direction, researched against award‑tier references (see sources below). **Everything is now one
self‑contained file — `prototype/index.html`** — containing both the premium **landing page** and the **app
flow**; the "Launch app" buttons open the tool in‑page (a gold wipe transition), so there is no broken
cross‑file link. The app screens inherit the same design system. More motion was added per feedback
(scroll‑progress bar, hero parallax + scale, card entrance with rotation, velocity‑reactive marquee skew,
wipe transition into the app).

**Design system (drop‑in tokens):**
- **Palette — "dark but not black":** warm espresso base `#0E0D0B`, surfaces `#16140F`/`#1C1917`, 1px
  hairlines `rgba(255,255,255,.07)`, warm off‑white text `#F4EFE6`, muted `#A29A8E`, **one** restrained accent —
  champagne gold `#D4A574` / `#EBDAB0`. (No neon, no blue→purple gradient, no pure black — all flagged as
  "cheap/AI‑template" tells.)
- **Type:** **Clash Display** (display, tight negative tracking) + **Satoshi** (body) — Fontshare, free
  commercial, *variable* (on‑brand for kinetic type). Avoid Inter/Space Grotesk.
- **Atmosphere:** SVG `feTurbulence` film‑grain overlay, slow blurred **aurora orbs**, tasteful glass nav,
  fine hairlines, 60‑30‑10 balance.
- **Motion stack (all MIT / GSAP‑free):** **Lenis** smooth scroll + **GSAP ScrollTrigger** (parallax scrub,
  batched reveals), masked word‑reveals on headings, **magnetic** buttons, **custom cursor**, velocity‑free
  CSS **marquee**, **vanilla‑tilt** cards. Gated by `prefers-reduced-motion`; **transform/opacity‑only**.
- **Resilience:** content is visible without JS; libraries (CDN) only *enhance*. If GSAP/Lenis fail to load,
  the page still reads premium (static).
- **Dogfooding:** the hero is itself live kinetic typography — the sample line cycles through the 9 looks,
  demoing the product on the landing page.

**Still placeholder:** the 9 looks are CSS stand‑ins; "Launch app" routes to the wireflow; no real
generation/export yet (Function/Technique phases).

## v0.5 — Depth‑first rebuild: a real engine (verified)

After the honest QM review (docs/06), rebuilt from the ground up, **depth over breadth**, with a **visual‑QA
loop** (headless Chromium screenshots — `tools/shot.mjs`/`interact.mjs`). The prototype is now `index.html`,
**built** from `index.src.html` by `tools/build.mjs` which **inlines premium variable fonts as base64**
(`@fontsource` Bricolage Grotesque + Archivo) → fully **self‑contained** (renders offline and in QA; matches
the monolith/OGraf‑inline decision).

- **Real engine:** every frame is a **pure function of normalized time t∈[0,1]** over an **in → hold → out**
  timeline — the exact `goToTime`/seek model Resolve needs. No infinite CSS loops.
- **Real transport:** working **scrubber** (frame‑accurate seek) + **play‑once**; `?frame=` deep‑link for QA.
- **Stagger model (bucket B):** per‑token animation with **unit** (char/word/line), **order**
  (L→R/R→L/center/random), **amount**; standard **easing library** (expo/cubic/quint/back/elastic/bounce…).
- **Functional controls (no dead knobs):** In/Out animator, easing, unit/order/amount, in/hold/out timing,
  variable‑font **weight**, colour, accent. All verified to change the render (screenshot + DOM assertions).
- **Flagship look "Aurum":** Bricolage Grotesque, high‑contrast warm‑white, mask‑rise entrance + fade‑sink
  exit, gold accent underline that draws in; tasteful dark stage (no cheap checkerboard).
- **Verified visually:** in/hold/out frames captured and reviewed (`shots/f_in|f_hold|f_out.png`); controls
  exercised via `interact.mjs` (no page errors).

**Next (build on this foundation):** the full **A+B+C** control set (host‑parity: text‑on‑path/shading stack;
selector depth: falloff Shape/ease‑high‑low/Mode/wiggly/char‑content; fast‑title UX: variant gallery + seeds,
one‑click styles, swappable In/Out presets, auto‑caption/beat — per docs/08), then more looks, then the
WebGL‑in‑Resolve PoC for the L3 effects.

*Next: get feedback on the premium look, then carry the same design tokens into the app screens
(`app.html`), and begin the Function phase (make a couple of looks "real" with the seek‑able engine from
Dossier #1).*

**Design sources:** Anthropic frontend‑aesthetics guide; Material/Apple dark‑theme (off‑black); Fontshare
(Clash Display/Satoshi licensing); CSS‑Tricks "Grainy Gradients"; Codrops (kinetic type, GSAP+Lenis);
darkroomengineering/Lenis (MIT); GSAP ScrollTrigger/SplitText (now free); Awwwards Luxury/Typography;
Vercel/Linear/Stripe as dark‑premium references.

## v0.4 — Refocus: from "website" to TOOL workspace

Feedback: "too much website, too little web‑tool UI/UX — focus on the tool." The landing is now a **slim
entry** (hybrid is fine); the energy went into a real **workspace** (modern info‑management), and the
**variant matrix** from Dossier #5 is now the right‑hand control surface.

**Workspace layout** (`#app`):
- **Top bar:** brand · the lyric **line field** · format / duration / fps mini‑segments · **🎲 Generate** ·
  **⬇ Export** (mock toast describing the `.ograf.zip`) · **✕** (Esc).
- **Left — Variants library:** a scrollable column of **live mini‑previews**, each labelled with its **seed**
  + ♥ favorite; **＋** generates more. This is the "fresh ideas" wall.
- **Center — Stage:** large live preview on an alpha checkerboard + transport (replay/scrub) + a
  resolution/fps/alpha badge.
- **Right — the Look Matrix:** the 10 axes (Material · Intro · Idle · Outro · Unit · Order · Type · Palette ·
  Motion · Background) as grouped chips, each with **🎲 randomize‑this‑axis** and **🔒 lock**, plus an
  editable/copyable **SEED** field at the bottom.

**Engine wired (lightweight, in‑browser):** `combine` produces random variants (locked axes preserved);
`encode`/`decode` map a variant ↔ a compact **seed** (the seed *is* the data — no DB). Material · Palette ·
Type · Motion are wired to actually change the preview; the remaining axes are interactive + part of the seed
(full visual wiring lands in the Function phase). Selecting a library card loads it into the stage + matrix;
editing any axis updates the variant, its seed, and its thumbnail live.

**Still placeholder:** look visuals are CSS stand‑ins; Generate/Export are mocks (no real OGraf yet). The point
of this pass is the **tool UX**: generate → browse the library → tune the matrix → lock/seed → export.
