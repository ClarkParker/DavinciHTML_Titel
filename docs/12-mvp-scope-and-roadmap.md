# MVP‑Scope & Roadmap

*Aus der Mind‑Map (`docs/11`) geschnitten. Prinzip: **das Kleinste, das unsere Lücke besetzt** — frei, web,
schön, mit Alpha, in Resolve. Stand: 2026‑06‑22.*

---

## Phase 0 — Fundament (die 4 Pfeiler als lauffähiges Skelett)
Ein leeres, aber **korrektes** Gerüst, auf dem alles andere sitzt:
- deterministische Engine `f(t)` + Token‑Modell (Block → Zeile → Wort → Zeichen) + **In → Hold → Out**‑Timeline + Scrub
- der gemeinsame **Feld‑Vertrag** (MSDF) als Stub
- **Seed = Zustand** (im Link)
- **ankerbasiertes, normalisiertes Layout**

## Phase 1 — Free MVP Core (der Creator‑Loop) ← das erste echte, teilbare Produkt
**DRIN:**
- eine Zeile rein
- **Varianten‑Galerie** (Seeds; „surprise me" aus kuratierten Presets)
- **kuratierte Regler:** In/Out‑Animator · Easing · Stagger (Motion‑Stil: Einheit + Richtung + Stärke) · Farbe · Font · Timing
- **6 schöne Start‑Looks** (CSS/Canvas — garantiert in jeder Resolve‑Edition)
- **Vorschau:** frame‑genaues Scrubben auf Alpha‑Schachbrett
- **Export:** PNG‑Sequenz + WebM‑Alpha + **OGraf‑Paket**
- Formate 16:9 / 9:16 / 1:1

**DRAUSSEN (kommt später):** WebGL‑Effekte · volle Profi‑Tiefe · ProRes/HDR · Lyric/Beat‑Sync · KI‑Captions ·
eigene Fonts hochladen · Zusammenarbeit.

## Phase 2 — Tiefe & Reichweite
- **voller AE‑Range‑Selector** + Per‑Property‑Animatoren (Profi‑Modus, per progressive disclosure)
- mehr Looks · **Variable‑Font‑Achsen‑Animation**
- **Lyric/Beat‑Sync** (Offline‑Beatgrid) ← der Musiker‑Hook
- **ProRes 4444**‑Export · **Resolve‑WebGL‑PoC** (Sonde → echter WebGL‑Look live in Resolve)
- eigene Fonts hochladen

## Phase 3 — FX‑Module & Premium
- 3D‑Extrude · Glas/Metall · Partikel · **voller Font‑Morph** · HDR
- **Effekt‑Marktplatz** (Community‑Module) · Modell „freie Engine + bezahlte Packs"

## Reihenfolge
**Phase 0 → 1** (= erstes echtes Produkt) **→ 2 → 3.** Frei/Premium trennt sich nach Aufwand: leichte
Feld‑Effekte frei, schwere als spätere Packs.

## Deine Entscheidungen (Standards gesetzt — jederzeit kippbar)
1. **Lyric/Beat‑Sync:** Standard = **Phase 2**. Früher (v1) = stärkerer Musiker‑Hook, aber mehr Scope.
2. **Start‑Looks in v1:** Vorschlag **6**.
3. **Varianten in v1:** Standard = **Seed‑Shuffle über kuratierte Presets** (offline, frei) statt schwerer KI.
